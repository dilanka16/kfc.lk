# 🍗 KFC Sri Lanka (kfc.lk) - Next-Level React Frontend Clone

A modern, high-performance, and visually stunning frontend revamp of the official **KFC Sri Lanka** ([kfc.lk](https://kfc.lk/)) web ordering portal. Built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## ✨ Features

- 🔴 **KFC Brand Identity**: Signature Colonel Red (`#e4002b`), crisp typography with Oswald and Plus Jakarta Sans, micro-interactions, and 3-stripe KFC motif.
- 🍗 **Authentic Sri Lanka Menu**: Complete with official KFC Sri Lanka items, prices in LKR (Rs.), high-resolution images, and spicy tags:
  - Hot & Crispy Chicken (1Pc, Quarter, Half, 6Pc & 8Pc Buckets)
  - Burgers (Zinger, Big Boss, Double Decker, Caribbean, Loaded Cheese, Ramen Burger)
  - Authentic KFC Biriyani & Biriyani Sawan Platter
  - Hot & BBQ Drumlets, Wings, Crispy Twister Wraps & Submarines
  - Sides & Desserts (Fries, Popcorn Chicken, Pepsi, Chocolate Mousse)
- 🛵 **Delivery vs. Pickup Switcher**: Instant location selector covering major Sri Lankan cities (Colombo, Kandy, Galle, Negombo, Dehiwala, Rajagiriya, etc.) with a simulated "Locate Me" button.
- 🛒 **Interactive Bucket (Cart) Drawer**:
  - Item customizations (Hot & Crispy vs Original Recipe, dips, sides)
  - Real-time price breakdown (Subtotal, Delivery Fee, Packaging Fee, Discount, Total)
  - Interactive Coupon / Promo Code Engine (`KFC10` for 10% off, `FEAST500` for Rs. 500 off, `FREESHIP` for zero delivery fee)
- 💳 **Streamlined Checkout Flow**:
  - Delivery details with contact information
  - Multiple payment options: Cash on Delivery, Card on Delivery (portable POS), Online Payment
  - Order celebration confetti (`canvas-confetti`) with live simulated order preparation and rider tracking!
- 📍 **Store Locator / Our Restaurants Modal**:
  - Searchable directory of flagship KFC outlets across Sri Lanka with hotlines (`011 555 5555`), opening hours, and one-click pickup selection.
- 🛡️ **100% Local Poultry & Trust Section**:
  - Highlights partnerships with local Sri Lankan poultry farmers and fresh daily preparation.
- 📱 **Fully Responsive**: Mobile-first design optimized for mobile screens, tablets, and desktops.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/dilanka16/kfc.lk.git

# Navigate into project directory
cd kfc.lk

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```
